# 0021 verify: barcode scanning

How `/check verify` proves each acceptance criterion of [index.md](index.md). "e2e" means the database backed api suite or Playwright against Postgres; no check needs a physical scanner (a wedge scan is a sequence of keydown events with `code` values and an Arabic `key`; a phone keyboard entry is keydown events with key code 229 and an empty `code` followed by `input` data), and the camera checks use Playwright's fake video capture with a recorded image of each format.

**Pilot setup (before the pilot week)**: on the pilot's phone and scanner, over the warehouse network: (1) 50 scans on the returns screen, the 95th percentile from Enter (or decode) to the result on screen (AC-3); (2) three real Bosta labels scanned, and whether the code is the tracking number; (3) the tag rehearsal over every style in stock, with the count of unknowns and conflicts. Record here the date, the phone, the scanner and its settings, the network, and each result. Not run yet.
