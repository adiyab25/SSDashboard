# Architecture decision records

One short file per decision that is costly to reverse. Copy [0000-template.md](0000-template.md),
take the next free number, and link the new record from the `## Decisions` section of each module
README it governs. Larger design choices that span the whole product live in `docs/specs/`; an ADR
records one decision inside a module or area.
